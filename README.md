# เรือนซ่อนวิญญาณ (The Veiled Thai House)

เกมสยองขวัญพิกเซลอาร์ตแนวไทย 2D สำหรับงาน Open House มหาวิทยาลัยบูรพา เล่นคนเดียว หรือเล่น 2 คนแบบ "จอกลาง + มือถือ" ผ่าน QR Code ก็ได้

- **Solo:** ทั้งเกมรันในเบราว์เซอร์ ไม่ต้องใช้เซิร์ฟเวอร์
- **Co-op:** จอกลาง (host) รันเกม · มือถือ P1 เป็นจอยเดิน · มือถือ P2 เป็น "ญาณทิพย์" (เรดาร์ + กระดิ่งตรึงผี)

## ในเกมมีอะไรบ้าง

**เกมเพลย์**
- 6 ช่วง: ป่ามืด → โถงรูปถ่าย → ห้องเครื่องเซ่น (สัมภเวสี) → โถงใน (ผีนางรำ) → สะพานข้ามภพ (วิ่งหนี) → รุ่งอรุณกับคุณลุง
- เก็บของเซ่นไหว้ 3 ชิ้น + เศษรูป 3 ชิ้น ต่อรูป ถวายของ แล้วบรรเลงระนาดให้จบเพลง เพื่อเปิดประตูหลังเรือน
- **ระนาดของแม่จันทร์ (ฉาก 4):** ระนาดเอกข้างหิ้งบูชาเล่นทำนอง 3 ท่อน (3, 4, 5 โน้ต สุ่มทุกเกม) ผู้เล่นฟังแล้วเคาะตามด้วยเลข 1–5 หรือแตะลูกระนาด (E = ฟังอีกครั้ง) เคาะผิดผีนางรำขยับเข้ามาใกล้ ผิดครบ 3 ครั้งเทียนดับและต้องเริ่มใหม่ ผีนางรำจะไม่ไปจนกว่าเพลงจบ (มือถือ P1 ใช้แป้นตัวเลขเดียวกับรหัสตู้)
- **ดิ้นให้หลุด:** ถูกผีคว้าตัวครั้งแรกในแต่ละห้อง (และทุกครั้งหลังฟื้นสติ) ยังไม่ตายทันที มีเวลา 3.2 วินาทีกด E / Space / ปุ่มสำรวจรัวๆ 8 ครั้ง หลุดแล้วผีชะงัก 2.6 วินาที ครั้งที่สองในห้องเดิมคือโดนจับ
- **สะพานข้ามภพ (หลังประตูหลังเรือน ก่อนรุ่งอรุณ):** ฉากวิ่งหนีราว 35–55 วินาที วาดด้วยโค้ดทั้งฉาก (ไม่ใช้ไฟล์ภาพ) ความมืดไหลตามมาจากเรือน ต้องวิ่งไปหาแสงทางขวา มีมือโผล่จากใต้สะพานคว้าขา 4 จุด (กดรัวๆ ให้หลุด) และสัมภเวสีโผล่ขวางทางฟังเสียง 2 จุด (ขึ้นคำว่า "หยุดเดิน" ต้องปล่อยปุ่มเดินภายใน 1 วินาที) ตายแล้วเริ่มจากจุดที่ผ่านล่าสุด และทุกครั้งที่ตายจุดเดิม มือจะคว้าหลวมขึ้น 25% กระดิ่งของ P2 หยุดความมืด 4 วินาทีและปลดมือให้
- ผีแต่ละตัวมีกฎของตัวเอง:
  - **ผีนางรำ** ขยับได้เฉพาะตอนไม่มีใครมอง — ส่องไฟฉายใส่แล้วเธอหยุดนิ่ง หันหลังหรือไฟกะพริบดับเธอจะพุ่งเข้ามา
  - **สัมภเวสี** ตาบอด ล่าด้วยเสียงฝีเท้า — เดินแล้วมันพุ่งมา ยืนนิ่งแล้วมันหาไม่เจอ
  - เสียงกระซิบสอนกฎตอนเจอผีครั้งแรก
- ระบบซ่อนตัว: ซ่อนในตู้/ตุ่มแล้วปิดไฟฉาย ผีจะค้นหา แล้วค่อยๆ หายไปและไปโผล่ด้านหลังผู้เล่น (เปิดไฟฉายตอนซ่อน = ผีเห็น) · ระหว่างซ่อนจะมองเห็นห้องผ่านช่องแคบๆ เท่านั้น (ตู้ = บานประตูไม้ปิดเข้ามาจากสองข้าง, ตุ่ม = ขอบตุ่มด้านล่างกับเงาฝาด้านบน) ผียิ่งเข้าใกล้ช่องยิ่งแคบ ขอบจอมืดและเต้นตามจังหวะหัวใจ (`renderHidingView`)
- ฉาก 1 ป่า: เดินไปสักพักจะมีเสียงฝีเท้าเดินตามจากด้านหลัง ช้ากว่าครึ่งก้าว หยุดเดินแล้วมันหยุดตาม (ปูกฎ "ยืนนิ่ง" ของสัมภเวสี, `echoForestStep`)
- ฉาก 5 รุ่งอรุณ (ครั้งเดียว): เดินออกจากประตูเรือนแล้ว ผีนางรำกับสัมภเวสีปรากฏจางๆ หน้าประตู ก้มไหว้ แล้วสลายเป็นละอองแสง (`renderDawnFarewell`)
- ต่อเศษรูปครบ: คัทซีนสั้นบนจอ (~6 วินาที, กดข้ามได้หลัง 1.2 วินาที) เศษรูปทั้งสามลอยมาประกอบกันกลางจอ แล้วในรูปโถงเรือนที่ว่างเปล่ามีร่างสีซีเปียของตัวละครที่เลือกค่อยๆ ปรากฏตรงประตู (`playPhotoReveal`)
- ของลับ (ไม่บังคับ): ฉาก 1 มีใบปลิว Open House ม.บูรพา เปียกฝนตกอยู่ในพงหญ้า (เห็นชัดเมื่อส่องไฟฉาย) มีลายมือเพื่อน "ไปด้วยกันนะ ห้ามเบี้ยว!" เก็บได้แล้วหน้าจบขึ้นตำแหน่ง "ผู้รักษาคำสัญญา" (`buuHotspots`, `readBuuFlyer`)
- หลังมีคนเล่นจบ 15 นาที หน้าแรกจะมีผีนางรำยืนจางๆ บนทางเดิน โผล่แวบๆ ทุก 14 วินาที ให้คนที่ต่อคิวเห็น (`TITLE_GHOST_KEY` ใน localStorage, `.t-ghost`)
- ตู้ในฉาก 4 ล็อกด้วยรหัสเลขไทย 4 หลัก (สุ่มทุกเกม) เขียนบนยันต์ที่ผนัง อ่านได้เมื่อส่องไฟฉาย
- พิธีถวายของต้องเรียงลำดับ: ธูปเทียน → พวงมาลัย → พานขนม (ผิดลำดับ หน้าต่างพิธีปิด เปลวเทียนในห้องดับ ในความมืดหน้าผีนางรำโผล่ตรงหน้าแวบหนึ่ง แล้วเธอขยับเข้ามาใกล้ขึ้น ต้องกลับไปที่หิ้งบูชาเพื่อเริ่มใหม่)
- ฉาก 3 (ครั้งเดียวต่อเกม): ถ้ายืนนิ่งตอนสัมภเวสีอยู่ใกล้ จะมีเสียงแม่เรียกชื่อตัวละครที่เลือก (นนท์/ริน) ให้เดินเข้าไปหา ล่อให้ผู้เล่นขยับ (`maybeCallPlayerName`)
- คัทซีนงานศพตอนเลือก "ริน" ใช้ภาพที่ตัวละครผมบ๊อบแบบนักเรียนหญิง (`intro_s1_fN_rin.png` สร้างจาก `tools/rin_bob.py`)
- ฉากหลอนที่จัดวางไว้: เงาที่ประตูเรือนตอนฟ้าแลบ, ไฟดับแล้วมีหน้าโผล่ที่หน้าต่าง, เทียนดับแล้วกระพรวนดังข้างหลัง
- ฉาก 2 ผนังรูปถ่าย (ครั้งเดียวต่อเกม): เดินผ่านใต้ผนังแล้วดวงตาในรูปทั้ง 8 ใบเรืองแดงทีละรูปและมองตามผู้เล่น จากนั้นดับพร้อมกันพร้อมเสียงทุบ (`renderPortraitScare`, ตำแหน่งตาใน `PORTRAIT_EYES`)
- จุดหักมุม: เสียงกระซิบที่คอยช่วยคือเพื่อนที่เพิ่งไปงานศพมา (เฉลยตอนจบ)
- **ภาพใกล้ (close-up):** อ่านบันทึกของเรือนหรือใบปลิว แล้วภาพกระดาษจริงขึ้นเต็มจอ ข้อความเขียนลงบนกระดาษ (ลายมือหมึกซีดสำหรับบันทึก, ตัวพิมพ์เลอะฝนสำหรับใบปลิว) กด E / แตะ / Esc เพื่อปิด แล้วตัวละครพูดต่อ (`playCloseup`, ตำแหน่งข้อความใน `LORE_BOX`)
- ตอนจบใหม่ 2 ฉาก (ภาพนิ่งพร้อมคำบรรยาย กดข้ามได้): ถ้าอ่านบันทึกครบ 3 หน้า จะเห็นเรือนที่สงบ แม่จันทร์รำจบต่อหน้าหลวงสุนทร ตาเหมือนได้กินอิ่ม (`playTrueEnding`, เสียง `blessing`) · แล้วทุกคนตื่นที่ห้องพักผู้ป่วยพร้อมเสียงเครื่องวัดชีพจร บนโต๊ะมีมือถือ พวงมาลัย ใบปลิว (`playHospitalWake`, เสียง `monitor_beep`; นนท์เห็นทั้งห้องและเงาคุณลุงที่ประตู ส่วนรินเห็นโต๊ะข้างเตียง) · หน้าจบใช้ภาพตามตอนจบที่ได้
- jumpscare ใช้ภาพหน้าผีแบบวาดเต็มจอ (`jumpscare_dancer.jpg` / `jumpscare_sam.jpg`) และหน้า "ถูกจับได้" มีภาพพื้นหลังของผีตัวที่จับ (`gameover_*.jpg`)
- ฉากตบท้ายก่อนหน้าจบ: ตื่นมาตอนเช้าแล้วเจอข้อความจาก "เพื่อนสนิท" 2 ข้อความในมือถือ ข้อความแรกยังไม่ได้อ่าน ส่งมาเตือนเรื่องรถก่อนรถคว่ำ 1 นาที ส่วนข้อความที่สองเพิ่งเข้ามา (`playPhoneSting`; กดข้ามได้หลัง 1.5 วินาที)
- ผีแต่ละตัวมีเสียงประจำตัวที่ดังซ้าย/ขวาตามตำแหน่งผี: ผีนางรำเป็นทำนองคล้ายระนาดเพี้ยนๆ (เงียบเมื่อโดนไฟฉายส่องจนหยุดนิ่ง), สัมภเวสีเป็นเสียงหายใจครืดคราด
- **บันทึกของเรือน (ไม่บังคับ):** ห้องละ 1 แผ่น (ฉาก 2–4) ติดผนัง เห็นชัดเมื่อส่องไฟฉาย เล่าว่าผีนางรำคือ "แม่จันทร์" ลูกสาวหลวงสุนทรที่ตายก่อนคืนรำแก้บน และสัมภเวสีคือ "ตาเหมือน" คนเฝ้าเรือนที่ไม่มีใครทำบุญให้ · อ่านแล้วภาพเป็นสีซีเปียแวบหนึ่ง · พบครบ 3 หน้า ตอนพิธีเห็นแม่จันทร์รำจบ คุณลุงเผยว่าตัวเองคือหลวงสุนทร และหน้าจบได้ตำแหน่ง "ผู้ไขความลับแห่งเรือน" (ข้อความอยู่ใน `LORE` ใน game.js)
- จับเวลา + นับครั้งที่ถูกจับ → ฉายาตอนจบ (🏆 ผู้กล้าแห่งบูรพา ฯลฯ) และหอเกียรติยศประจำบูธ (เก็บในเครื่อง, หน้าแรกโชว์ 3 อันดับ) + ปุ่ม **"รับการ์ดผู้รอดชีวิตลงมือถือ"** ขึ้น QR ให้ผู้เล่นสแกนแล้วได้การ์ด PNG 1200×630 (ชื่อ ฉายา สถิติ ตราพิเศษ) บนมือถือตัวเอง: ข้อมูลรอบเล่นอัดอยู่ใน `#...` ของลิงก์ `card.html` บน Vercel แล้วมือถือวาดการ์ดเอง ไม่อัปโหลดอะไร ใช้เน็ตมือถือได้แม้มือถือต่อโน้ตบุ๊กบูธไม่ได้ (`public/souvenir.js`, `showSouvenirQr`)
- **เลือกตอนจบ:** หน้าประตูเรือน คุณลุงถามว่า "จะให้สัญญากับข้าไหม?" เลือกด้วย ←/→ แล้วกด E, คลิก/แตะ หรือใช้ปุ่มเดิน + ปุ่มใหญ่บนมือถือ P1 (ไม่มีใครตอบ 30 วินาที = สัญญา) · **สัญญา** = ตอนจบเดิม · **ไม่รับปาก** = ตื่นที่โรงพยาบาลเหมือนกัน แต่คืนนั้นไฟกะพริบ เสียงระนาดแว่วมา แล้วผีนางรำโผล่ปลายเตียง → หน้าจบ "ตอนจบ: ผิดสัญญา" (`askPromise`, `playBrokenPromise` ใน game-extra.js)
- **คืนที่สอง (โหมดยาก):** ปลดล็อกในเครื่องนั้นหลังมีคนเล่นจบ 1 ครั้ง ปุ่มสีแดงที่หน้าแรก · ข้ามบทนำ เข้าป่าทันที · ผีเร็วขึ้น 20%, ห้องมืดกว่าเดิม, กระดิ่งชาร์จ 16 วิ (ปกติ 12), ความมืดบนสะพานไล่เร็วขึ้น 18% · จบแล้วได้ตรา "ผู้รอดคืนที่สอง" (หน้าจบ, หอเกียรติยศ, การ์ดบนมือถือ) · ค่าทั้งหมดอยู่ใน `NIGHT2` ใน game-extra.js
- สัมผัสพิเศษ: ทำให้เห็นในที่มืดและเห็นจุดสำรวจทั้งหมด แลกกับผีวิ่งเร็วขึ้น
- จุดบันทึกอัตโนมัติ ถ้าแท็บรีเฟรชกด "เล่นต่อ" ได้

**บอกทางผู้เล่น** (เพิ่มหลังเพลย์เทสต์ — คนเล่นเข้าใจปุ่ม แต่ไม่รู้ว่าต้องทำอะไร)
- แถบ 🎯 เป้าหมายด้านบนจอ: บอกสิ่งที่ต้องทำต่อทีละข้อ เปลี่ยนเองเมื่อทำสำเร็จ และบอกให้ย้อนกลับถ้าลืมเก็บของ (ข้อความอยู่ใน `currentObjective()`)
- ลูกศรสีทองชี้จุดถัดไป ถ้าติดอยู่ขั้นเดิมเกิน 15 วินาทีจะใหญ่ขึ้นพร้อมบอก "มาที่นี่ แล้วกด E"
- การ์ดบทตอนเข้าฉากใหม่ ("บทที่ 2 · โถงรูปถ่าย" + เป้าหมายของฉาก)
- เสียงกระซิบตอนเข้าเรือนบอกเหตุผลของภารกิจ (ต้องคืนของเซ่น 3 อย่าง + เศษรูป 3 ชิ้น ที่หิ้งบูชา)
- คำแนะนำปุ่มหลังบทเปิด (แยกข้อความคอม/มือถือ)
- **เสียงกระซิบใบ้เมื่อติด:** ถ้าเล่นอยู่ขั้นเดิมนาน 45 วินาที (ไม่นับเวลาบทพูด/พัก/คัทซีน/ซ่อนตัว) เสียงเพื่อนจะกระซิบบอกแบบเจาะจงขึ้นในกรอบสีเขียว แล้วซ้ำทุก 35 วินาที สูงสุด 3 ครั้งต่อขั้น (ข้อความอยู่ใน `STUCK_HINTS`)

**เมนู**
- ตั้งค่า (หน้าแรกและในเมนูพัก): ระดับเสียง, ปิดเสียง, ความแรง jumpscare (เต็ม/ลด/ปิด), ลดการเคลื่อนไหว, เต็มจอตอนเริ่ม — จำค่าไว้ในเครื่อง
- พักเกม (Esc หรือปุ่มพักบนแถบด้านบน): หยุดทั้งเกมจริง, กลับสู่หน้าแรกโดยเก็บเซฟไว้, หรือล้างเซฟให้คนถัดไป
- หน้าแรกแบบเมนูเครื่องเกม (ตามภาพปก): เล่นต่อ / เริ่มเกมใหม่ / เล่น 2 คน / ตั้งค่า / วิธีเล่น, เลือกตัวละครแล้วตัวละครยืนกลางฝนเปลี่ยนตาม, ใช้ ↑↓ (หรือ W/S) + Enter/E บนคีย์บอร์ดได้, Esc ปิดหน้าต่าง
- หน้าต่าง "วิธีเล่น" สรุปปุ่ม เป้าหมาย และกฎผีแต่ละตัว
- ปุ่ม "ล้างเซฟ (ให้คนถัดไป)" ในหน้าตั้งค่าและเมนูพัก สำหรับส่งเครื่องต่อที่บูธ
- **โหมดบูธ:** ถ้าไม่มีใครกดอะไรเลย 3 นาทีระหว่างเล่น (หรือ 75 วินาทีที่หน้าจบ) เกมจะนับถอยหลัง 15 วินาที แล้วล้างเซฟและกลับหน้าแรกเอง กดปุ่มใดก็ได้ (รวมปุ่มบนมือถือ) เพื่อยกเลิก · ถ้าพิมพ์ชื่อหอเกียรติยศไว้แต่ลืมกดบันทึก จะบันทึกให้ก่อน (ปรับเวลาได้ที่ `BOOTH_IDLE` ใน game.js)
- **Attract mode:** หน้าแรกไม่มีใครกดอะไร 40 วินาที จะเล่นภาพวนของเกม 5 ฉาก (ป่า → โถงรูป → สัมภเวสี → ผีนางรำ → รุ่งอรุณ + สถิติอันดับ 1 ของบูธ) พร้อมคำโปรยและ "กดปุ่มใดก็ได้เพื่อเล่น" ให้คนที่เดินผ่านหันมาดู · กดหรือแตะครั้งแรกแค่ปิดภาพวน ไม่ไปกดเมนูข้างหลัง · ไม่ขึ้นทับหน้าต่างที่เปิดอยู่ (ปรับได้ที่ `ATTRACT_AFTER` / `ATTRACT_SLIDES`)
- **กันเกมค้าง:** ถ้าเฟรมเกม error จะซ่อมตำแหน่งที่เพี้ยน (NaN) ให้เอง ถ้ายัง error ต่อเนื่อง ~3 วินาที จะบันทึกแล้วโหลดหน้าใหม่ (กด "เล่นต่อ" ได้)
- ฟอนต์ Sarabun + Chakra Petch อยู่ในโปรเจกต์ (`public/assets/fonts/`, SIL OFL 1.1) เปิดที่บูธได้แม้ไม่มีอินเทอร์เน็ต
- ภาพปก 1600×900 + favicon + ภาพตอนแชร์ลิงก์ (`public/assets/cover.png`)

**ภาพ**
- ความมืดจริงในเรือน: เห็นผีชัดเฉพาะตอนโดนไฟฉาย นอกนั้นเห็นแค่เงาจางๆ
- ป่ามีฟ้าแลบ + ฟ้าร้อง, หมอกเลียดพื้น, ฟิล์มเกรน, ไฟฉายกะพริบตอนผีใกล้, ภาพสั่นตอนผีจ่อตัว
- ผีมี glitch ภาพฉีก/สีแยก, เงาซ้อนตอนไล่ล่า, ผีนางรำโยกตัวแบบท่ารำ
- Jumpscare เต็มจอ (หน้าผีพุ่ง + จอสั่น + แฟลชแดง)
- คัทซีนเปิดเรื่อง 30 ฉาก (`public/story-intro.js`): งานศพเพื่อน → ขับรถกลับ → รถชน → เขตแดนกึ่งกลาง → ตื่นในป่า ภาพพิกเซลขยับได้ รูปหน้าคนพูด เสียงพูดแบบเกมเก่าของแต่ละคน เล่นอัตโนมัติ (กดเพื่อไปต่อ/ย้อน/ข้ามได้, มือถือ P1 กดไปต่อได้) โลกในเกมหยุดรอและไม่นับเวลา · ดูซ้ำได้จากเมนูหน้าแรก
- ฉากเปิดประตูเป็นช็อตต่อเนื่อง: บานประตูแง้มตามบานพับ ตัวละครเดินเข้าความมืด กล้องดันเข้า แล้วเฟดเข้าฉากถัดไป (กดข้ามได้, ประตูเดิมซ้ำจะสั้นลง)
- Cutscene อื่นแบบหนัง: ซูม/แพนช้าๆ, เฟดต่อภาพ, แถบดำบนล่าง
- บทพูดพิมพ์ทีละตัวพร้อมเคอร์เซอร์ หยุดจังหวะตามเครื่องหมายวรรคตอน (ตัดคำไทยถูกต้อง), กรอบบทพูดแบบไม้ลงรัก
- รองรับ `prefers-reduced-motion` (ปิดการสั่น/แฟลชแรง)

- หน้าตาในเกมเข้าชุดกับหน้าแรก: แถบบน/ปุ่มล่างพื้นมืด เส้นแดงบาง ไอคอนเส้นแทน emoji (ของเซ่น/เศษรูปใช้ภาพพิกเซลจากเกม), แถบเป้าหมายแบบแบนเนอร์
- หน้าถูกผีจับเต็มจอสีแดงมืด บอกชื่อผีและวิธีรอดจากผีตัวนั้น · หน้าจบเต็มจอบนภาพรุ่งอรุณ (ภาพค่อยๆ ซูมออก)
- หน้าต่างทุกอัน (พักเกม, ตั้งค่า, ห้อง QR, ถวายของ, ตู้รหัส, กรอบรูป) และจอมือถือ P1/P2 ใช้กรอบ/ปุ่มชุดเดียวกัน ไม่มี emoji
- ของในฉาก (ตุ่ม ตู้ หิ้ง โต๊ะ) ถูกปรับโทนให้มืดและหม่นตามห้อง (`PROP_GRADE`) ไม่ดูเหมือนแปะทับ — ยกเว้นยันต์รหัสที่ต้องอ่านออก
- **ให้เหมือนเกมจริง (อาจารย์ขอ):** ห้องในเรือนมืดขึ้นจนต้องใช้ไฟฉาย, แสงเทียน/ตะเกียงกะพริบไม่เป็นจังหวะ, ผีตัวใหญ่ขึ้น (สูง 300 เทียบผู้เล่น 238 — ระยะจับเท่าเดิม)
- ห้องมีชีวิต: เปลวไฟบนตะเกียงและเทียนบนหิ้ง, ลำแสงจันทร์จากหน้าต่างค่อยๆ หายใจ, นานๆ ครั้งมีเงาคนเดินผ่านหน้าต่าง (ตำแหน่งอยู่ใน `ROOM_LIFE`)
- เกมตอบสนอง: ฝุ่นฟุ้งที่เท้าทุกก้าว, เก็บของแล้วภาพค้างจังหวะหนึ่ง + แฟลชทอง + ของลอยขึ้นไปที่ตัวนับ (ตัวนับเด้ง), เข้าห้องใหม่กล้องซูมแล้วค่อยๆ ถอยออก
- ป้าย `[E] ...` (มือถือ `แตะ`) ลอยเหนือจุดที่กดได้แบบเกมคอนโซล แทนป้ายลอยกลางจอแบบเดิม

**เสียง**
- เสียงบรรยากาศแต่ละฉากจากเสียงจริง CC0 (ฝน, นก, ตุ๊กแก, หมาหอน, ประตูลั่น, ฝีเท้าบนพื้นไม้) + เสียงสังเคราะห์เสริม
- เพลงธีม (`assets/audio/title_theme.mp3`, โทนฝันๆ เศร้าๆ) ใช้เฉพาะช่วงที่อารมณ์เข้ากัน: หน้าแรก, คัทซีนเปิดเรื่องช่วงงานศพ/ขับรถ (เงียบลงก่อนรถชน แล้วกลับมาเบาๆ ตอนอยู่ในห้วงจิต), ฉากรุ่งอรุณกับหน้าจบ — ในเรือนไม่มีเพลง ให้เสียงบรรยากาศสร้างความกลัว · ควบคุมด้วย `setMusicLevel()` ผ่านแถบเสียง/ปิดเสียง
- เสียงที่เพิ่มรอบนี้: ฆ้องตอนขึ้นการ์ดบท, เสียงเลื่อน/เลือกเมนูหน้าแรก, สวิตช์ไฟฉาย, มุดเข้า/ออกที่ซ่อน (ระหว่างซ่อน เสียงฝนและบ้านจะอู้อี้เหมือนอยู่ในตู้ แต่เสียงผียังชัด), หมุนรหัส/รหัสผิด/กลอนดีด, เปิดหน้าต่างถวายของ/กรอบรูป/ตู้รหัส
- ไฟฉายส่องเจอผีหลังจากคลาดกันไปสักพัก มีเสียงแทงใจแบบหนังผี (เสียงสีแหลม + เสียงทุ้ม), เสียงกระดาษเก่าตอนเปิดบันทึก
- เสียงผีดังตามระยะและมาจากฝั่งที่ผีอยู่ (ใส่หูฟังใช้หลบผีได้), เสียงหัวใจเต้นเร็วขึ้นเมื่อผีใกล้
- แถบปรับเสียง + ปุ่มปิดเสียง (จำค่าไว้), เสียงหยุดเองเมื่อสลับแท็บ

**มือถือ**
- เล่นคนเดียวบนมือถือ: แนวนอนมีปุ่มลอยบนภาพแบบเกมมือถือ, แนวตั้งมีหน้าบอกให้หมุนจอ + ปุ่มเต็มจอ
- มือถือ P1: ปุ่มใหญ่เปลี่ยนข้อความตามสถานการณ์ ("🔍 สำรวจตู้…", "▶ ไปต่อ", "⏭ ข้ามฉาก", "🖼️ วางเศษรูป", "🕯️ ฟื้นสติ") — เล่นจนจบได้โดยไม่ต้องแตะจอกลาง
- มือถือ P2: แผนผังบอกชื่อจุดและติ๊ก ✓ จุดที่เสร็จแล้ว, กระดิ่งมี cooldown แสดงเวลา, ช่วงสะพานข้ามภพแสดงแผนผังระยะวิ่ง + แนวความมืด + สถานะมือคว้าขา/สัมภเวสีฟังเสียง (`renderP2BridgeRadar`)
- ปริศนาที่ต้องคุยกัน: P2 เห็นรหัสตู้, ลำดับพิธี และโน้ตระนาดเลขไทยของท่อนที่กำลังเล่น (`ranatCoopHint`) ส่วนมือถือ P1 เปลี่ยนเป็นแป้นตัวเลข / ปุ่มเลือกของเซ่นเอง
- Android สั่นตอนกดปุ่ม / ผีใกล้ / ถูกจับ

## วิธีรัน

ต้องใช้ Node.js 18 ขึ้นไป (ชุดทดสอบใช้ 21 ขึ้นไป) โปรเจกต์ไม่มี dependency ไม่ต้อง `npm install`

```bash
npm run local
```

เปิด `http://localhost:3000` บนจอกลาง มือถือที่ต่อ Wi-Fi วงเดียวกันสแกน QR ได้เลย (QR ใช้ IP ในวง LAN ให้อัตโนมัติ)

ตัวเลือกเพิ่มเติม:

| ตัวแปร | ผล |
|---|---|
| `PORT=8080` | เปลี่ยนพอร์ต |
| `PUBLIC_TUNNEL=1` | เปิด URL https สาธารณะผ่าน localhost.run (ต้องมี `ssh`) — ปิดไว้เป็นค่าเริ่มต้นเพื่อไม่ให้เครื่องถูกเปิดสู่อินเทอร์เน็ตโดยไม่ตั้งใจ |

## แนะนำสำหรับวันงาน (บูธ)

1. ใช้ `npm run local` บนโน้ตบุ๊กที่บูธ และใช้ Wi-Fi/hotspot ของบูธเอง — หน่วงต่ำที่สุด และส่งข้อมูลแบบ push (SSE) จริง
   - **ที่บูธ (Windows): ดับเบิลคลิก `booth-start.bat`** เพื่อเปิดเซิร์ฟเวอร์และเปิดเกมเต็มจอใน Chrome ที่ตั้งให้เล่นเสียงได้ทันที เปิดมาก็ได้ยินเพลงหน้าแรกเลย (ปิดหน้าต่างเกมด้วย Alt+F4) · ถ้าเปิดในเบราว์เซอร์ปกติแล้วเบราว์เซอร์ยังไม่ให้เล่นเสียง จะมีหน้า "กดปุ่มใดก็ได้เพื่อเริ่ม" ขึ้นก่อน กดแล้วเพลงจะเริ่มพร้อมเมนู
   - **ก่อนเกมขึ้นเต็มจอ จะมีหน้าต่างเช็คบูธ** (`tools/booth-check.js`): บอก IP ที่ QR จะใช้, ไฟร์วอลล์ Windows ยอมให้มือถือเข้าไหม (Wi-Fi แบบ Public จะบล็อกถ้ายังไม่อนุญาต node.exe และหน้าต่าง "Allow access" มักซ่อนอยู่หลังเกม), มีอินเทอร์เน็ตไหม แล้ว**พิมพ์ QR ทดสอบมือถือ** ให้สแกนภายใน 25 วินาที (Enter = ข้าม) ถ้ามือถือเปิดได้ = โหมด 2 คนใช้ได้บน Wi-Fi นี้ ถ้าสแกนแล้วค้าง Wi-Fi อาจกันเครื่องคุยกันเอง → เปิดฮอตสปอตจากมือถือแทน · ถ้ามีเรื่องต้องดู หน้าต่างจะรอ 60 วินาที (กดปุ่มใดก็ได้เพื่อเปิดเกม) · รันแยกได้: `node tools/booth-check.js` (ต้องเปิดเซิร์ฟเวอร์ก่อน)
2. ทดสอบสแกน QR ด้วยกล้อง iPhone และ Android ก่อนเปิดบูธ
3. ถ้าจอกลางเผลอรีเฟรช กด "เล่นต่อ" ที่หน้าแรกได้ (บันทึกจุดล่าสุดไว้ในแท็บนั้น) มือถือไม่ต้องสแกนใหม่ถ้าห้องยังไม่หมดอายุ
4. **เมนูเจ้าหน้าที่: กด `Ctrl+Shift+K`** บนจอกลาง (ใช้ได้ทุกหน้า เกมหยุดระหว่างเปิด) แล้วกดตัวเลข:
   - `1` ล้างเซฟ กลับหน้าแรกให้คนถัดไป · `2` ข้ามไปฉากถัดไป (ให้ของที่ควรมีครบ ใช้ช่วยคนที่ติดหรือตอนคิวยาว) · `3` ให้ผีหยุด 20 วินาที
   - `4` ปิด/เปิดเสียง · `5`/`6` เสียงเบาลง/ดังขึ้น · `7` เปิดโหมดโชว์หน้าบูธทันที (หน้าแรก) · `0` หรือ Esc ปิดเมนู
   - ด้านบนบอกสถานะ: อยู่ฉากไหน เวลาเล่น ผี มือถือ P1/P2 ต่ออยู่ไหม ที่อยู่ LAN ของเครื่อง เสียง ความลื่น (fps) และจำนวนข้อผิดพลาด
5. ก่อนเปิดบูธ รัน `npm test` หนึ่งรอบ — มีเทสต์ที่เปิด Chrome แบบไม่มีหน้าจอแล้วเล่นเกมเองตั้งแต่หน้าแรกจนถึงฉากจบ ถ้าผ่านแปลว่าเนื้อเรื่องเดินได้ครบ

## Deploy บน Vercel

`vercel.json` ส่งทุก `/api/*` ไปที่ `api/index.js` และเสิร์ฟ `public/` เป็นไฟล์ static

Serverless function หลาย instance **ไม่ใช้หน่วยความจำร่วมกัน** ถ้าจะเล่น co-op บน Vercel ให้เชื่อม Redis:

| ตัวแปรสภาพแวดล้อม | หมายเหตุ |
|---|---|
| `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN` | จาก Upstash console |
| หรือ `KV_REST_API_URL` + `KV_REST_API_TOKEN` | ตั้งให้อัตโนมัติเมื่อเพิ่ม Vercel KV / Upstash integration |

ถ้าไม่ได้ตั้งค่าไว้ ระบบจะใช้หน่วยความจำของ instance เดียว (โหมด Solo ใช้ได้ปกติ ส่วน co-op อาจหลุดเมื่อมีผู้เล่นพร้อมกันหลายห้อง) ดูสถานะได้ที่ `/api/server-info` (`"store": "upstash"` หรือ `"memory"`)

Unit test ครอบคลุม: วงจรชีวิตห้อง, การยืนยันตัวตน host/ผู้เล่น, ลำดับและเพดานคิว input, การหมดอายุห้อง, การกรองข้อมูล state, rate limit, ตำแหน่งบิตของ QR ตามมาตรฐาน ISO 18004 (รันทั้งกับ memory store และ fake Upstash)

`tests/playthrough.test.js` เปิดเซิร์ฟเวอร์กับ Chrome/Edge แบบไม่มีหน้าจอ แล้วเล่นทั้งเกม: บทนำ → ฉาก 1–5 (เก็บของทุกชิ้น, ปลุกสัมภเวสี, ใส่รหัสตู้ผิดแล้วถูก, ถวายผิดลำดับแล้วถูก, ต่อรูป) → หน้าจบ จะตกถ้ามี error ในหน้าเว็บหรือขั้นไหนไม่ไปต่อ และทดสอบเมนูเจ้าหน้าที่ด้วย (เปิดเมนู, ข้ามฉาก 1→5, รีเซ็ตแล้วเซฟหาย) ใช้เวลาประมาณ 20 วินาที · ถ้าเครื่องไม่มี Chrome/Edge เทสต์นี้จะถูกข้าม (ระบุตำแหน่งเบราว์เซอร์เองได้ด้วย `CHROME_PATH`) เทสต์นี้เล่นปริศนาระนาด (รวมเคาะผิด 1 ครั้ง) และวิ่งข้ามสะพานข้ามภพจนถึงปลายทางด้วย ส่วนเทสต์ที่สามตรวจการดิ้นหลุดจากผี (ครั้งแรกหลุดได้ ครั้งที่สองโดนจับ ไม่กดก็โดนจับ), การเคาะระนาดจากมือถือ, การตายบนสะพานทั้งสองแบบ และจุดเริ่มใหม่หลังตาย

### API (สรุป)

| Route | ใครเรียก | หมายเหตุ |
|---|---|---|
| `POST /api/create-room` | จอกลาง | คืน `code` 4 หลัก + `hostToken` (ลับ) |
| `POST /api/join-room` | มือถือ | `{code, role}` → `playerToken`; เข้าซ้ำตำแหน่งเดิมจะแทนที่เครื่องเก่า |
| `POST /api/sync-state` | จอกลาง | ต้องมี `hostToken`; ส่ง state + `seq`, รับ input ที่ค้างอยู่ |
| `POST /api/player-input` | มือถือ | ต้องมี `playerToken`; P1 = เดิน/สำรวจ/ซ่อน/ไฟฉาย, P2 = กระดิ่ง/ญาณทิพย์ |
| `GET /api/room-state` | มือถือ | state สาธารณะของห้อง (ไม่มี token) |
| `GET /api/events` | ทั้งคู่ | SSE เฉพาะ local server |
| `GET /api/qr?text=` | จอกลาง | QR เป็น SVG data URL (รับเฉพาะ URL http/https) |

## ปรับสมดุลเกม

ค่าทั้งหมดอยู่ใน `CONFIG` ด้านบนของ [public/game.js](public/game.js) เช่น ความเร็วผู้เล่น/ผี, ระยะจับ, เวลาที่ผีค้นหาก่อนหายไป, cooldown ของกระดิ่ง และความถี่ในการ sync

ค่าที่น่าจะปรับหลังให้คนลองเล่น:
- ความมืดแต่ละฉาก: ตาราง `DARKNESS` ใน `renderDarknessAndFlashlight` (ฉาก 3–4 = 0.9; ถ้ามืดไปลองลดเป็น 0.85)
- ความดังฝน: `loopSample('rain', 0.75)` (ในป่า) และ `0.4` (ในเรือน) ใน `setAmbientScene`
- ผีนางรำโหดไป → ลด `DANCER_UNSEEN_MULT`; สัมภเวสีไม่น่ากลัวพอ → เพิ่ม `SAMPHAWESI_HEAR_SPEED`
- เกณฑ์ฉายาตอนจบ: `rankFor()` (ขยับเป็น 7 และ 10 นาที เพราะเกมยาวขึ้น); หอเกียรติยศเก็บใน localStorage คีย์ `buu-horror-hof-v1`
- เนื้อหาเสริมอยู่ใน [public/game-extra.js](public/game-extra.js): `STRUGGLE` (จำนวนครั้ง/เวลาดิ้นหลุด), `RANAT` (ความยาวแต่ละท่อน, จำนวนครั้งที่พลาดได้, ความเร็วโน้ต), `CHASE` (ความยาวสะพาน, ความเร็วความมืด `WALL`, เวลาเตือนก่อนต้องหยุด `WARN_MS`, ตำแหน่งและความยากของแต่ละจุดใน `EVENTS`)
- สะพานยากไป → ลด `need` ใน `CHASE.EVENTS` หรือลด `CHASE.WALL`; ง่ายไป → เพิ่ม `need` หรือลด `CHASE.MAX_GAP`
