## 6. Exploit / Security Test (P1)

> ทดสอบบนเครื่อง/preview ของทีมเองเท่านั้น

| ID | ขั้นตอน (curl) | ผลที่คาดหวัง (หลังแก้) | อ้างอิง |
|---|---|---|---|

| X-02 | `curl -X POST /api/player-input -d '{"code":"<ห้องจริง>","action":"stun_ghost"}'` จากเครื่องที่ไม่ได้ join | 401/403 | H-04 |

| X-04 | `curl /api/server-info` (local) | ไม่มี `activeRooms` | H-04 |
| X-05 | ส่ง `action` แปลก (`"__proto__"`, `"x".repeat(1e6)`) | ถูกปฏิเสธ (whitelist), body > 16KB ได้ 413 | H-04, L-08 |
